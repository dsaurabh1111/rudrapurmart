
### `images/README.txt`

```text
Place optimized grocery product images in this folder.

Recommended formats:

- WebP
- AVIF
- JPG
- PNG

Example:

images/
├── apple.webp
├── banana.webp
├── broccoli.webp
├── milk.webp
├── bread.webp
└── mango.webp

The current demo uses emoji-based product visuals, so the website works without external image dependencies.
